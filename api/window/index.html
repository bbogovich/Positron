    Window¶

    sealed class Positron.Window

    A live Positron window. It wraps the native backend and the IPC router, exposing a small surface for loading content, registering C# handlers callable from JavaScript, pushing events to the web content, and showing native file dialogs. You obtain one via the configure callback of App.Run — you do not construct it yourself.

    Loading content¶

    LoadUrl¶

    public void LoadUrl(string url)

    Navigates the web content to a URL — e.g. a file:// or http:// address, or app://localhost/ when WindowOptions.ServeDirectory is set. Throws if url is null or empty.

    window.LoadUrl(new Uri(Path.Combine(AppContext.BaseDirectory, "wwwroot", "index.html")).AbsoluteUri);

    LoadHtml¶

    public void LoadHtml(string html)

    Loads an HTML string directly into the web content. Throws if html is null.

    window.LoadHtml("<!doctype html><h1>Hello</h1>");

    IPC handlers¶

    Handle (synchronous)¶

    public void Handle<TArg, TResult>(string channel, Func<TArg, TResult> handler)

    Registers a synchronous C# handler invokable from JavaScript via window.positron.invoke(channel, payload). TArg is deserialized from the invoke payload; the returned TResult is serialized back as the result.

    Handle (asynchronous)¶

    public void Handle<TArg, TResult>(string channel, Func<TArg, Task<TResult>> handler)

    The async overload — the handler returns a Task<TResult>. Use it for I/O-bound work.

    window.Handle<GreetRequest, GreetResponse>("greet", req => new GreetResponse($"Hi, {req.Name}!"));

window.Handle<SaveRequest, bool>("save", async req =>
{
    await File.WriteAllTextAsync(req.Path, req.Contents);
    return true;
});

    Both TArg and TResult must be declared [JsonSerializable] on the source-generated JSON context passed to App.Run. See IPC and Security (validate handler arguments).

    Events¶

    Emit¶

    public void Emit<TPayload>(string channel, TPayload payload)

    Pushes an event to JavaScript listeners registered via window.positron.on(channel, cb). Fire-and-forget; there is no response.

    window.Emit("tick", new Tick(DateTimeOffset.Now.ToString("HH:mm:ss")));

    Lifecycle¶

    Close¶

    public void Close()

    Closes the window and exits the native run loop, unblocking App.Run. Raises Closed. Safe to call from a handler or any thread.

    Closed¶

    public event Action? Closed

    Raised after the window's native run loop has been asked to exit via Close. Use it to release app resources (timers, file handles) tied to the window's lifetime.

    var timer = new Timer(_ => window.Emit("tick", DateTime.Now), null, 0, 1000);
window.Closed += () => timer.Dispose();

    Native file dialogs¶

    ShowOpenFileAsync¶

    public Task<string?> ShowOpenFileAsync(Files.OpenFileOptions? options = null)

    Shows a native open-file dialog on the UI thread and returns the selected absolute path, or null if the user cancelled. Read the file with System.IO.File from the host. See OpenFileOptions.

    ShowSaveFileAsync¶

    public Task<string?> ShowSaveFileAsync(Files.SaveFileOptions? options = null)

    Shows a native save-file dialog and returns the chosen absolute path, or null if cancelled. Write the file with System.IO.File from the host. See SaveFileOptions.

    string? path = await window.ShowOpenFileAsync(
    new Positron.Files.OpenFileOptions { AllowedExtensions = ["txt", "md"] });
if (path is not null)
{
    string text = await File.ReadAllTextAsync(path);
}

    Note

    The renderer can reach equivalent functionality through the built-in window.positron.dialog.* / window.positron.fs.* channels — see IPC. These Window methods are the C# host-side API for the same dialogs.
